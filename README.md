# TagMaid · AI 标签整理

供个人使用的 Edge Manifest V3 扩展。在侧栏中手动预览并应用当前窗口的标签整理：连接自己的 OpenAI 兼容 API，按主题分组或只排序；也可不配置 API，直接按域名排序。

## 安装

1. 打开 Edge 的 `edge://extensions`，开启「开发人员模式」。
2. 点击「加载解压缩的扩展」，选择本项目的 **`extension`** 文件夹。
3. 在扩展菜单中点击 TagMaid，或使用 `Alt+Shift+Y` 打开侧栏。快捷键冲突时可在 `edge://extensions/shortcuts` 修改。
4. 使用 AI 时，填写 API 基础地址（例如 `https://你的服务地址/v1`）、模型名称和密钥，点击「保存并授权 API 站点」。也可以填写完整 `/chat/completions` 地址。只用域名排序可跳过此步。
5. 选择整理模式，可附加一句要求，检查「发送前查看数据范围」，再生成预览。
6. 分组模式可调整新组名称、颜色和标签去向；排序模式按预览列出的顺序排列，可排除个别标签。检查后确认应用。

更新代码后，在扩展管理页面点击 TagMaid 的「重新加载」，再重新打开侧栏；仅重启浏览器可能继续使用已缓存的后台脚本。

生成预览时会播放像素小女仆整理标签的 6 帧循环动画，完成、取消或失败后自动停止；动画不表示百分比进度，也不会延迟本地排序。默认每轮 1.2 秒；系统开启「减少动态效果」时改为每轮 2.4 秒的低速循环，保留等待反馈。原始图集及生成说明保存在 `assets/animation`。

## 界面语言

侧栏顶部可选择「简体中文 / 日本語 / English」，无需配置 API。首次使用按浏览器界面语言匹配：中文使用简体中文、日文使用日文，其他语言回退英文；手动选择仅保存于本机，并同步到本机已打开的 TagMaid 侧栏。

切换后立即更新设置、按钮、预览说明、颜色名称与应用自身的状态和错误提示。当前预览、组名与颜色编辑、标签去向、排除项和输入内容保留，不重新请求 AI、不改变浏览器标签。浏览器或服务返回的原始诊断保留原文。

AI 新组名默认使用点击「生成」时选定的语言；附加要求明确指定其他语言时优先遵从该要求。生成期间切换语言只更新界面，下次生成才使用新语言。网页标题、已有组名以及已经生成或手动编辑的组名不会翻译。

扩展管理页的名称、说明及浏览器管理的入口文案按浏览器语言显示；侧栏手动选项控制侧栏及后续 AI 新组名。（实现参考：[Chrome 扩展国际化文档](https://developer.chrome.com/docs/extensions/reference/api/i18n)）

运行插件不需要 Node.js、构建工具或安装依赖。仅开发测试需要 Node.js 22 或更新版本。

## 五种模式

| 模式 | 行为 |
| --- | --- |
| 全部重新整理 | 确认后解除参与整理的标签原有分组，重新分类 |
| 仅创建新组（默认） | 保留已有分组；未分组标签只能进入新组或保持未分组 |
| 允许加入已有组 | 保留已有组名、颜色和原有成员；未分组标签可加入已有组、新组或保持未分组 |
| AI 排序 · 不分组 | AI 按主题、项目或任务排列未分组标签；不创建或修改分组 |
| 域名排序 · 不分组 | 本地按完整域名升序排列，同域名保持原先顺序；无需 API、不发送数据 |

会记住最近选择的模式。所有操作限定在侧栏所在窗口；固定标签、浏览器内部页面、文件页面等非 HTTP(S) 标签不参与。混合分组里的这些排除标签保留原状。

两种排序模式都先预览、确认后应用，并支持撤销。参与排序的标签按预览顺序集中移到窗口末尾，即所有已有组后面；已有组的成员、名称、颜色、折叠状态和组间次序保留。完整域名分别排序，例如 `docs.example.com` 与 `www.example.com` 分开排列。排除项及预览后新增标签不参与本次排序；已有组与这些标签的相对顺序保留，绝对位置可能随其他标签移动而变化。

预览中的「保持未分组」会将该标签解除分组（模式一）或继续保持未分组（模式二、三）；「排除 · 保持原样」完全不修改该标签归属。已有组不可改名或改色；新组可编辑，并能添加新的空组再分配标签，空组不会实际创建。

## API 与隐私

- 使用 Chat Completions 的非流式接口：`POST .../chat/completions`。不需要模型支持专门的 JSON 输出模式；响应仍须满足提示中指定的 JSON 格式。
- 仅 AI 模式在主动生成预览时发送网页标题、经处理的网址和必要编号；网址的查询参数、片段及嵌入的账号密码会移除。标题、域名和路径本身仍可能包含私人信息。域名排序不发起 API 请求或申请 API 站点权限。
- 模式三还会发送已有组名以及其中 HTTP(S) 网页的标题和处理后网址，作为分类参考。附加要求也会发送。
- 不读取正文，无内容脚本、统计上报、转发服务器或后台定时整理。
- 仅为配置的 API 站点申请实际访问权限。清单中的可选 HTTPS 范围用于支持用户自填接口，并不代表安装时获得所有网站访问权限。
- 默认密钥只存于 `chrome.storage.session`，关闭浏览器后失效。勾选「在此设备记住密钥」后存入 `chrome.storage.local`，不使用云同步；该存储不提供独立加密保护。取消勾选并保存会移除持久保存的密钥。
- 公网接口要求 HTTPS，仅 `localhost` 和 `127.0.0.1` 支持 HTTP。本地免密接口可留空密钥。不跟随接口重定向。
- 请求最多等待 90 秒，支持取消；发生失败时不会自动重试收费请求。没有真实 API 凭据时，开发验证使用本地模拟服务，不代表具体供应商的模型分类效果已验证。

## 撤销与异常恢复

每个窗口保留最近一次整理前的标签顺序和分组信息，存于当前浏览器会话，关闭窗口或退出浏览器后不再保留。

撤销尽可能恢复仍在原窗口且没有被固定的标签，不重新打开已关闭的网页，不将已移动到其他窗口的网页拉回。后来新增的标签不会被关闭；恢复原有顺序时，它们在标签栏中的绝对位置可能变化。组的浏览器内部 ID 可能改变，但名称、颜色、折叠状态和成员会恢复。

生成结束、预览期间及应用前会检查标签状态。已关闭、移出当前窗口或后来固定的标签会从预览中移除，其余标签的手动分配、组名和颜色保留；新增标签保持原样，留到下一次整理。因移除成员而变空的组会自动移除；没有可应用的标签时按钮禁用，原因显示在按钮旁。

待整理标签发生导航或被手动改组、目标已有组失效或改名改色时，仍会提示冲突；可以重新生成，或排除冲突标签、调整去向后继续。单纯调整标签顺序不会使预览失效，撤销以实际应用前的状态为准。应用错误直接显示在确认按钮旁。应用失败会尝试回滚；无法完成时保留恢复记录，使用「恢复上次中断的整理」重试。应用或撤销期间请暂时不要手动移动或关闭标签。

## 开发与验证

```powershell
npm install
npm test
npm run check
npm run package
```

`npm test` 验证数据清理、AI 输出校验、五种模式、预览增删对账、导航与改组冲突拦截、应用回滚和撤销边界；单元测试的浏览器 API 使用模拟实现。`npm run check` 检查清单资源、脚本语法和界面引用。`npm run package` 生成 `dist/TagMaid` 可加载目录。

2026-10-10 在 Windows / Edge 154.0.4258.62 的独立配置中验证了真实原生侧栏：三种模式的预览、编辑、应用及撤销，手动新增分组与排除标签，组内顺序恢复，后台停止后重启、侧栏重载、模式记忆，导航后的过期方案拦截，以及关闭或固定标签后的撤销。300px 和 380px 宽度无横向溢出，未发现未解释的页面脚本错误。浏览器验证使用 Playwright 和调试协议，因为当前环境没有 Browser 技能。

API 端到端验证使用本地模拟服务，覆盖正常 JSON、429、非法响应和取消；测试副本仅增加本地服务的预授权，生产清单没有安装时的网站访问权限。真实服务商凭据、模型分类质量和原生站点授权确认弹窗的点击尚未验证。

2026-10-10 本次修复另通过 24 项逻辑测试及独立 Edge 154.0.4258.62 原生侧栏回归（headless 浏览器中的实际 sidePanel 页面，382px 宽）：生成等待期间增删标签、预览后新增/固定/移窗、手动编辑保留、全部候选失效、真实应用与撤销，以及按钮旁后台错误提示。该轮仍使用本地模拟 AI 接口，页面控制台无错误。

源文件职责：`core.js` 处理范围和方案校验，`api.js` 调用 AI，`engine.js` 应用与恢复，`background.js` 提供队列和侧栏入口，`sidepanel.*` 与 `styles.css` 提供界面。

语言文案集中在 `i18n.js`，浏览器管理的名称与入口文案在 `_locales`。`npm run test:language-browser` 在独立 Edge 配置中运行真实侧栏的语言回归；默认使用 Windows 的 Edge 安装位置，可通过 `EDGE_PATH` 指定程序路径。测试只给临时扩展副本预授权本地模拟 API，截图与结果保存在 `test-results/language-*`。
