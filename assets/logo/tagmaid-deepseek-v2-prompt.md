# DeepSeek 娘 8-bit 像素头像 v2

使用内置图像生成工具制作的 8-bit 像素头像。源图 `tagmaid-deepseek-v2.png` 为 1254×1254 透明 PNG；`scripts/generate-icons.ps1 -DeepSeek` 以最近邻导出 16、24、32、48、96、128 像素运行图标。默认绿色素材仍用于标准外观。

网络视觉参考：[游民星空报道及配图](https://www.gamersky.com/news/202609/2219292.shtml)。只参考蓝色鲸鱼娘、女仆装的视觉方向；未将报道配图打包为扩展资源，也不将角色声明为官方形象。

## 最终生成提示词

把参考角色重新画成真正复古8-bit像素游戏头像。最重要：8-BIT PIXEL ART，严格方块像素网格，类似48x48原生sprite整数放大，有限的16色调色板，深蓝色一像素阶梯轮廓，无抗锯齿，无平滑线条，无柔和渐变，无3D，无矢量，不要把原插画简单降低清晰度。重新设计为粗像素的Q版蓝鲸女仆头像。保留深海蓝长发、头两侧鲸鳍、白色女仆发箍、一小根弯呆毛、蓝眼睛、圆脸腮红和调皮小嘴，胸前蓝蝴蝶结。头发用藏蓝、钴蓝、天蓝三块平涂色，发梢是蓝色；大眼睛简化为很少几块像素。头像占正方形画布80%，四边至少8%真实透明留白，呆毛不碰顶，鲸鳍不触边，完整显示。纯透明alpha背景，背景必须没有任何图案、颜色、光晕、棋盘格、投影。不要文字或水印。输出单个精致、清晰可读、胖嘟嘟的8-bit像素角色头像，用于浏览器工具栏和侧栏。
