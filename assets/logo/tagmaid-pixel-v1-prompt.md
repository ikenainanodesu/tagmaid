# TagMaid 像素 Logo

生成方式：内置图像生成工具。

设计素材：`tagmaid-pixel-v1.png`。本次交付为独立 Logo 设计素材。

## 完整生成提示词

用途：logo-brand。为 TagMaid 浏览器标签整理插件设计一个正式、精致、可爱的像素风品牌图标。只输出一个完整 logo，正方形画布，真实透明背景。核心创意：极简像素小女仆头像与浏览器标签页融合；主体是薄荷绿/森林绿短发小女仆的正面头像，奶油白女仆蕾丝头饰的上缘巧妙形成三个整齐排列的浏览器标签页阶梯轮廓，让人联想到整理好的标签组。两个深色小像素眼睛，简洁亲切的表情，脸部暖奶油色；底部小小的绿色蝴蝶结。以深森林绿 #253d37 做统一粗像素轮廓，主色 #267257、浅薄荷绿、奶油白，极少暖桃色点缀。审美是专业独立软件的 16-bit 像素艺术标志，像精心手绘的 48×48 游戏精灵，用最近邻整数放大，所有边缘由清晰方形像素和有规律的阶梯组成，限制色板，平涂。正面、紧凑、对称、醒目的整体剪影，主体占画布约 82%，居中，四周足够安全边距，细节克制，适合浏览器扩展图标。不要文字、字母、水印、展示板、多个方案、外框、背景色块、渐变、阴影、发光、模糊、抗锯齿、3D。头饰与标签页是一个一体化设计，不要另外漂浮的网页窗口或杂物。
