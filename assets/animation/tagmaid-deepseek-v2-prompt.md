# DeepSeek 娘 8-bit 六帧等待动画 v2

使用内置图像生成工具，以 `assets/logo/tagmaid-deepseek-v2.png` 为角色身份与像素画风参考。源图 `tagmaid-deepseek-sorting-v2.png` 为 1536×1024 透明 PNG，3列×2行。运行 `scripts/generate-animation.ps1 -DeepSeek` 导出 1152×192 横条，单帧 192×192，在侧栏按 96×96 显示。

动作：拿起标签卡片、移至胸前、放到右侧、眨眼、复位，配合鲸尾摆动。沿用现有六帧播放契约：1.2秒循环，减少动态效果时2.4秒，等待区隐藏后停止。默认绿色素材仍用于标准外观。

## 完整生成提示词

为这个8-bit像素DeepSeek鲸鱼娘制作六帧循环动画sprite sheet，严格保留参考头像的粗方块8-bit像素画风与同一张脸：深海蓝长发、亮蓝发梢、蓝眼睛、鲸鱼侧鳍、白色发箍和小呆毛、圆脸小猫嘴，蓝白女仆装和蓝蝴蝶结。新增二头身小身体和身后向右翘起的大蓝鲸尾，尾巴腹侧白色。她坐着整理浏览器标签页小卡片。有限16色平涂色板，清晰的深蓝阶梯像素轮廓，仿64x64原生分辨率每帧的复古游戏sprite，用大块方形像素，无抗锯齿、无渐变、无柔焦、无平滑插画。输出1536x1024图集，精确3列2行，每帧512x512正方形，一共六帧。每个格子内固定角色头部中心与大小、身体位置和卡片基线。四边保留至少40像素透明留白，不裁切呆毛头鳍鲸尾，格子之间不串画。阅读顺序：帧1双手在身前准备拿左侧卡片，睁眼；帧2右手拿起卡片，鲸尾略抬；帧3双手抱卡片到胸前，鲸尾最高；帧4右手把卡片移到右侧卡片堆，眼睛稍眯；帧5放下卡片眨眼微笑，鲸尾回落；帧6双手回到第一帧位置，重新睁眼，鲸尾回到初始位置。三个标签卡片是简单蓝白像素小矩形，没有文字。每帧微小连续变化，不能变角色。透明背景必须严格alpha为0，不能有蓝色光晕、渐变背景、地面、投影、棋盘格、面板或任何不透明背景！仅画人物和三个卡片，没有桌子，没有字、数字、分格线或水印。
