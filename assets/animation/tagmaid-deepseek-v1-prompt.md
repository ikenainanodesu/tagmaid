# 鲸鱼娘六帧动画

通过内置图像生成工具，以原 `tagmaid-sorting-source.png` 的动作布局和 `assets/logo/tagmaid-deepseek-v1.png` 的角色设计共同约束重绘。
源图 `tagmaid-deepseek-sorting-v1.png` 为 1536×1024、3 列 2 行；使用 `scripts/generate-animation.ps1 -DeepSeek` 输出 1152×192 透明动画条。原版图集保留。播放时序沿用绿色版，减少动态效果时仍低速循环。

## 完整提示词

用途：像素动画精确改绘，透明 PNG sprite sheet。图1是需要编辑的原版 TagMaid 6帧整理动画图集；图2是已经确定的新鲸鱼娘头像，作为唯一角色设计标准。将图1中全部6帧的绿色女仆逐帧重绘为图2的蓝发鲸鱼娘女仆。严格保留图1的3列2行网格、1536×1024画布、每格512×512、六帧角色大小和中心位置、每帧手部动作和标签卡片位置，帧序完全不变。帧1准备拿左侧卡片；帧2拿起；帧3举到胸前；帧4移向右侧；帧5放下并闭眼笑；帧6回到帧1姿势供循环。所有6帧头饰必须复制图2的蓝鲸徽章与侧边两瓣鲸尾发饰，头发和衣服统一为 #4D6BFE 钴蓝和深海军蓝，冰蓝高光，奶油白头饰、暖奶油皮肤，保持原脸型、表情和方形像素画法。标签卡片的绿色也改蓝色。角色头部固定，不能跨帧改变大小和发饰位置。每格周围保留透明安全边距，不能触及格边界，整体图集严格对齐可直接等分裁切；不需要格线或编号。真实透明背景，移除输入预览可能看起来像阴影的所有背景像素。有限色板硬边平涂像素艺术，无模糊、无渐变、无投影、无发光、无背景、无水印、无文字，输出只包含6帧角色及卡片。
