# 整理等待动画

由内置图像生成工具参考 `assets/logo/tagmaid-pixel-v1.png` 制作。

- 原始图集：`tagmaid-sorting-source.png`，1536×1024，3 列 × 2 行，共 6 帧。
- 插件资源：`extension/images/tagmaid-sorting-strip.png`，1152×192，6 帧横向排列。
- 重新生成运行资源：在 Windows PowerShell 运行 `./scripts/generate-animation.ps1`。
- 播放：每轮 1.2 秒，仅在生成预览期间播放；完成、失败、取消后隐藏并停止。系统启用减少动态效果时改为每轮 2.4 秒的低速循环。

## 完整生成提示词

用途：为 TagMaid 浏览器扩展制作可以直接切割使用的像素动画 sprite sheet。参考图片仅用于角色身份和色彩：相同森林绿短发、白色标签页形女仆头饰、暖奶油色皮肤、小蝴蝶结、粗深绿像素轮廓。新增小小的女仆上半身和双手，正在整理浏览器标签卡片。输出一张横向 1536×1024 的透明 PNG，严格排成 3 列 × 2 行，共 6 帧，每格 512×512，所有格子背景完全透明、无分隔线、无文字、无帧编号。各格角色大小、坐标、脸、头饰、色板、基线完全一致，头部绝不能缩放或改变角度，中心 x 相同；主体完全位于各格中央 80% 区域，不能触及格边界。镜头固定正面。人物腰像在格中央，左侧下方有两张淡薄荷色浏览器卡片，右侧下方有整齐叠放的卡片。动作由左到右再到下一行：第1帧双手准备拿左边卡片；第2帧左手拿起一张卡片；第3帧双手将卡片移动至胸前中央；第4帧右手将同一张卡片移向右侧卡片叠；第5帧轻轻放下卡片，眼睛愉快闭一下；第6帧双手回到初始位置、眼睛睁开，布局返回第一帧，能够无缝循环。只让手和卡片移动，头部和躯干固定；禁止六格出现六种不同角色。简洁清晰的 16-bit 手工像素精灵，每格视觉像 64×64 原生像素整数放大，极少颜色、硬方块边缘、平涂，无渐变，无柔光，无投影，无纹理，无抗锯齿。卡片像素形状简单，白色主体带绿色标签页凸起，避免任何文字。最终是单张六帧动画图集，不是六个各不相同的徽标。
